# ChatWatcher V2

ChatWatcher V2 is a Nicotine+ plugin that integrates features for monitoring and managing chat interactions. This plugin combines the functionalities of Played, Keywords, and Shitlist into a single, user-friendly interface built with GTK and Python.

## Features

- **Played**: Captures and logs now-playing messages, allowing users to manage their interactions and block unwanted users.
- **Keywords**: Monitors chat messages for specified keywords, logging profile views and downloads for better user engagement.
- **Shitlist**: Provides tools for managing keyword bans and IP ignores, ensuring a safer and more controlled chat environment.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd ChatWatcher V2
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

To use the ChatWatcher V2 plugin, ensure that you have Nicotine+ installed. Load the plugin through the Nicotine+ interface, and access the features via the main window.
